# FDM visual direction

An editorial research page whose proof is actual robot footage. The experience follows the requested order: overview video, architecture, pipeline, real-robot comparison.

## Visual system

- Paper `#f6f5f0`, ink `#202c28`, secondary text `#59665f`, forest accent `#25564c`, sage section ground `#e7ede6`.
- Libre Caslon Display for display headings (wider letterforms, refined from Instrument Serif); DM Sans for prose and controls. Both self-hosted.
- Maximum content width 1240px, 96px desktop outer gutters, 40px mobile total gutter; section rhythm 110px desktop / 64px mobile.
- Warm editorial typography alongside the original paper's green, blue and sand expert colors. Real footage provides visual texture; no fabricated robotics imagery.
- The first viewport is a full-width, silent real-robot video cover, with the FDM acronym in DM Sans and the official title in Libre Caslon Display. Paper, PDF and code links sit above five chapter shortcuts into one continuous real-robot video. The ink-colored video scrim, paper text and sage controls reuse the existing palette; no new accent color is introduced. All authors and affiliations sit below the official title on the cover, before the paper links. The overview video follows the cover.
- Signature interaction: switching training to inference removes the future-generation dependency from the diagram; task controls let visitors inspect the same methods side by side.
- Mobile: centered cover with wrapped controls, stacked pipeline, two-column comparison videos, each combining a full-size third view above two half-size wrist views, and a horizontally scrollable data table.
- Native video controls, keyboard focus, reduced-motion support, captions and a readable transcript. The decorative cover autoplays silently, with an explicit pause control, pausing offscreen or in hidden tabs. Reduced motion and disabled JavaScript show a static poster. The overview and comparison recordings remain user initiated.

## Evidence and limits

Figures and results come from the supplied manuscript. No conference-acceptance claim. The public title is Forward Dynamics Models, matching the paper. All 60 supplied recordings are complete after the source refresh. Website is static and portable under a GitHub Pages repository path.
